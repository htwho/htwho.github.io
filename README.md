# H.-T. Lai Website

This repository contains the source code for my academic personal website:

[https://htwho.github.io/](https://htwho.github.io/)

The site presents my academic profile, curriculum vitae, research projects, publications, presentations, and contact information. Its current research themes include geophysics, fault-zone thermal monitoring, and planetary science.

## Website Sections

- `Home`: research overview and featured project
- `About & CV`: profile, education, work experience, and recent activities
- `Publications`: selected journal papers and conference proceedings
- `Presentations`: conference talks, posters, and workshop contributions
- `Projects`: research and technical project portfolio
- `Contact`: academic links and contact information
