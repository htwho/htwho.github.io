<h3>Abstract</h3>

This project focused on the design and implementation of a geological database system with interactive web applications for storing, organizing, and presenting subsurface geological information. The goal was to improve accessibility to geological data and provide a practical platform for researchers and users to explore geological models and related records through a web-based interface.

The web application was developed to support interactive browsing and visualization of geological information, helping connect database content with user-oriented exploration tools. By combining structured geological records with browser-based interaction, the platform improves the usability of geological datasets and supports more efficient access to spatial and subsurface information in research and applied geoscience workflows.
