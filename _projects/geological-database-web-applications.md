### Abstract

This project focused on the design and development of a geological database platform with interactive web applications for storing, organizing, and presenting subsurface geological information. The main objective was to improve access to geological records and provide a more practical environment for exploring spatial, stratigraphic, and engineering-related data through a browser-based interface.

The system was built to connect structured geological records with user-friendly web tools, allowing users to search, browse, and visualize information more efficiently than through static files or disconnected datasets. By integrating database architecture with interactive frontend components, the platform supported a more accessible workflow for reviewing geological materials, site information, and related subsurface interpretations.

This project also served as a foundation for connecting database content with other web-based outputs, including geological models and visual exploration tools. As a result, the platform functioned not only as a storage system, but also as an interface layer that improved how geological information could be retrieved, interpreted, and shared in applied geoscience work.

### System Focus

- Organize geological and subsurface records in a structured database environment
- Develop web applications for browsing and querying geological information
- Support interactive visualization of geological datasets and related project outputs
- Improve the accessibility and usability of subsurface data for research and applied workflows
- Provide a browser-based interface that connects database content with user-oriented exploration tools

### Project Outcome

- Built a geological database framework for storing and managing subsurface information
- Developed an interactive web interface for data access and visualization
- Improved the efficiency of reviewing geological records compared with static documentation alone
- Created a platform that can support future integration with three-dimensional geological models and other digital interpretation tools
